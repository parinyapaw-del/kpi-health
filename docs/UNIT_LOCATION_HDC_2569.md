## วิธีการ (ต่างจากข้อ 3 ของ brief — แข็งแรงกว่า)

ใช้วิธีแบบ global และ exhaustive แทนการไล่ residual ทีละ tambon
- สำหรับ **ทุก** Excel row (246 rows, 22 อำเภอ) จะแจกแจง **ทุก subset** ของหน่วยบริการในจังหวัดนั้นที่มีผลรวม vector 90 มิติ
  (15 count keys × 6 age groups, ไม่รวม gender) เท่ากับ row นั้น **พอดีทุกช่อง**
- ใช้ DFS แตกกิ่งตามมิติที่มีตัวเลือกน้อยที่สุด (most-constrained dimension) และตัดกิ่งด้วยเงื่อนไข v≤rem กับ Σavail≥rem
- มี 3 rows ที่เกิน node budget (120402, 120408, 140602) จึงแจกแจงซ้ำแบบครบถ้วนบน pool ที่ตัดหน่วยซึ่งถูก fix โดย row อื่นแล้วออก
  (แต่ละหน่วยมีตำแหน่งได้ที่เดียว) ผลคือได้ 1 solution ต่อ row
- ไม่มีสมมติฐานเรื่อง "move/swap" จึงครอบคลุม swap โดยอัตโนมัติ (1201 ต้องใช้ swap: 15240 ↔ 23821)

**ผลรวม: ทุก row ใน 246 rows มีคำตอบ whole-unit ที่ unique พอดี 1 ชุด, ไม่มี row ใดชนกัน (disjoint), ไม่มีหน่วยที่ vector เป็นศูนย์**
→ สมมติฐาน ก (HDC มีตารางตำแหน่งหน่วยบริการของตัวเอง และนับทั้งหน่วย) ยืนยันได้ครบทั้ง 22 อำเภอ
→ **ไม่ต้องทดสอบสมมติฐาน ข** (split ตาม areacode) เพราะไม่มีอำเภอใดที่แก้ไม่ได้ [CONFIDENT]

อีก 13 อำเภอที่ตรงอยู่แล้วก็ถูกแก้ซ้ำแบบ exhaustive เช่นกัน ทุก row ได้ชุดหน่วยเดียวกับ pipeline ปัจจุบัน (ไม่มีทางเลือกอื่น)

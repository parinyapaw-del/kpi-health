# MOPH Open Data API — ใช้แทนไฟล์ Excel ได้ (ทดสอบ 2026-09-29)

Endpoint: `POST https://opendata.moph.go.th/api/report_data` · header `Content-Type: application/json`
Response: `{"data":[...], "total":"N", "limit":1000, "offset":0}` — **default limit 1000** ต้องส่ง `"limit"` ให้ ≥ total (หรือวนด้วย `"offset"`)
ช้า: DSPM 1 จังหวัด 1 ปี ≈ 30–40 วินาที → ควร cache ผล (อย่ายิงสดทุกครั้งที่เปิดหน้าเว็บ)

## 1) DSPM — `s_childdev_specialpp` ✅ ตรงกับ Excel 100% (อ่างทอง 2567/2568/2569 ทุกอำเภอ)
Body: `{"tableName":"s_childdev_specialpp","year":"2569","province":"15","type":"json","limit":10000}`
- 1 แถว = hospcode × areacode(8 หลัก) × monthly → รวมยอดเองด้วย `areacode[:4]` = อำเภอ (`1501` เมือง … `1507` สามโก้)
- field ต่อกลุ่มอายุ suffix `_9 _18 _30 _42 _60` → "รวมทั้ง 5 กลุ่มอายุ" = sum ทั้ง 5

| คอลัมน์ Excel | field |
|---|---|
| เป้าหมาย (1) | `target_*` |
| คัดกรอง (2) | `result_*` |
| สมวัยครั้งแรก (2.1) | `1b260_1_*` |
| สงสัยล่าช้า รอกระตุ้น | `1b261_*` |
| สงสัยล่าช้า ส่งต่อทันที | `1b262_*` |
| ติดตามได้ (3) | `follow_*` |
| สมวัย (3.1) | `1b260_2_*` |
| ไม่สมวัยหลังกระตุ้น รวม (3.2) | `improper_*` |
| 1B202…1B242 (3.2.1–3.2.5) | `1b202_*` … `1b242_*` |
| รอการติดตาม (4) | `wait30_*` |
| ติดตามไม่ได้ใน 30 วัน | `loss_*` |
| สมวัย เพศชาย/หญิง (มีเฉพาะไฟล์ 2569) | `1b260_m_*` / `1b260_f_*` |

สูตร % (ตรวจกับ Excel แล้ว): ร้อยละคัดกรอง = result/target · ร้อยละสมวัยครั้งแรก = 1b260_1/target ·
รวมสงสัยล่าช้า = 1b261+1b262 · ร้อยละสงสัยล่าช้า = รวมสงสัย/result · ร้อยละติดตามได้ = follow/1b261 ·
รวมสมวัย = 1b260_1+1b260_2 · ร้อยละสมวัย = รวมสมวัย/target

## 2) Coverage — `s_child0_5_pshyche_develop_coverage` ✅ ตรงกับ Excel (อ่างทอง 2567, 2569 รายอำเภอ)
⚠️ **ห้ามส่ง `province`** → ได้ `400 Parameter Invalid` (ตัวอย่างบนเว็บ MOPH ผิด) · ส่งแค่ `{"tableName":"...","year":"2569","type":"json"}` แล้ว filter `provcode` เอง
- ปี 2567/2568: 1 แถว/จังหวัด (77 แถว) → ทำได้แค่ระดับจังหวัด/เขต/ประเทศ
- ปี 2569: 1 แถว/อำเภอ (928 แถว) → ทำรายอำเภอได้ (`areacode[:4]`) · **ระดับตำบลทำไม่ได้** (ตรวจ 2026-09-30: `areacode` =
  รหัสอำเภอ + `0101` ทุกแถว และ `hospcode` ไม่ใช่หน่วยรายงานจริง — รหัสเดียวกันโผล่ในอำเภอต่างจังหวัด) → Coverage ลึกสุดคือหน้ารายจังหวัด (แถว = อำเภอ)
- `c_1…c_11` = คอลัมน์ (1)…(11) ใน Excel; **`c_8`, `c_10` (ร้อยละ) ไม่ส่งมา** ต้องคำนวณ: c_8 = c_7/c_3×100, c_10 = c_9/c_3×100

## กฎระดับอำเภอ/ตำบล = ที่ตั้งหน่วยบริการ (Phase 2, 2026-09-30) ✅ ตรง Excel HDC 100%
- รายงาน HDC ระดับ **อำเภอและตำบล** จัดกลุ่มตาม**ที่ตั้งของหน่วยรายงาน (hospcode)** ในทะเบียน MOPH GIS
  (`data/lookup/units.json`, ดู `data/lookup/SOURCE.md`) ไม่ใช่ `areacode` ของเด็ก
  - หลักฐาน: สระบุรี 2569 — รพ.สต.นายาว `01758` ตั้งอยู่ พระพุทธบาท แต่รายงานเด็ก areacode หนองโดน 4 คน → Excel HDC ให้
    หนองโดน 296 / พระพุทธบาท 1,123 = ยอดตามที่ตั้งหน่วย (ตาม areacode จะได้ 300 / 1,119 ไม่ตรง)
  - ท่าเรือ 2569 — รพ.ท่าเรือ `10768` (ตั้งอยู่ ต.ท่าเรือ) มีเป้ากระจาย จำปา 73 / ท่าเรือ 26 / ท่าหลวง 23 → Excel ให้ ต.ท่าเรือ 122 / จำปา 41
    = ตามที่ตั้งหน่วย (กฎ Phase 1 "เป้ามากสุด" จะได้จำปาผิด)
- หน่วยที่ไม่มีในทะเบียน (100/982 รหัส ปี 2569 ส่วนใหญ่คลินิกเอกชน/อปท.) ใช้ fallback = ตำบลที่หน่วยมีเป้ามากสุด → นับเป็น `inferredUnits` ของอำเภอ
  แสดงป้าย [INFERRED] บนเว็บ (ยืนยันแล้วเฉพาะเมืองอ่างทอง 2 หน่วย)
- ทุกหน่วยของ 8 จังหวัดเขต 4 ตั้งอยู่ในจังหวัดเดียวกับที่ API ตอบ (parameter `province`) → ยอดจังหวัด = ผลรวมอำเภอเสมอ
- รหัสผิดปกติที่ต้องรองรับ: hospcode `14O3F` (ตัวอักษร O) เก็บเป็น string · areacode อำเภอ `1310` (ปทุมธานี ไม่มีใน DOPA) → แถว pseudo
  "ไม่ระบุพื้นที่ (รหัส 1310)" ท้ายตารางจังหวัด นับในยอดรวมจังหวัด ไม่จัดอันดับ

## 3) DSPM ทุกจังหวัด (ทดสอบ 2026-09-29) — ⚠️ ไม่ตรงกับ Excel HDC ทุกจังหวัด
- ดึงด้วย `python3 scripts/fetch_all_dspm.py` (resume ได้, ข้ามจังหวัดที่มี cache แล้ว) · **ห้ามยิงขนาน** (`--workers` > 1 → HTTP 429) · 76 จังหวัด × 3 ปี ≈ 3.3 ชม.
- cache ทุกจังหวัดเก็บในเครื่องเท่านั้น (`.gitignore` ยกเว้น `15.json`) · raw ≈ 2.7 GB ใน `data/raw_api/`
- กรุงเทพฯ (`10`) API ได้ 0 แถวทุกปี — Excel ประเทศ เขต 13 ก็เป็น 0 → สอดคล้องกัน
- เทียบกับ Excel: อ่างทอง + 4–5 จังหวัดเขต 4 ตรง 100% แต่ นนทบุรี/ปทุมธานี/สระบุรี และ 11/12 เขต ต่าง 0.1–3% **ทั้งสองทิศ แม้ปีปิดแล้ว (2567)**
  - ไม่ใช่เรื่องเวลาดึง (ปีปิดก็ต่าง) · ไม่ใช่การนับตามจังหวัดของ hospcode (ข้ามจังหวัดแค่ 52 แถว, ลองแล้วไม่ตรง)
  - [UNCERTAIN] รายงาน HDC กับ Open Data API น่าจะใช้ข้อมูลคนละรุ่น
- **2026-09-30: เว็บเปลี่ยนมาใช้ API ทุกระดับ** (Save ตัดสินใจ) · ระดับประเทศ/เขตสร้างจาก `data/cache/dspm/<ปี>/provinces.json` (ผลรวมรายจังหวัด, commit) · verify นับความต่างกับ Excel เป็น warning
- ใช้ต่อได้: ขยายเว็บให้เจาะรายอำเภอจังหวัดอื่น (ต้องระบุว่าเป็นข้อมูล API และอาจต่างจากหน้า HDC เล็กน้อย)
